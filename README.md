# RoadForge Garage

RoadForge Garage is an independent automotive affiliate website focused on
truck accessories, vehicle-fitment guidance, product recommendations, and
buying guides.

## Affiliate program

The site uses the approved OEDRO/CJ affiliate tracking URL. Affiliate links are
marked with `rel="sponsored"`, and the disclosure is shown prominently on the
homepage.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm run start
```

The project uses the Next.js App Router and is ready for Vercel deployment.
